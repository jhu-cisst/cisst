The `cisst` package is a collection of libraries designed to ease the development of computer assisted intervention systems. It contains components for robotics, stereo vision, multitasking, real-time control, and mathematical/numerical utilities.

## Documentation

Comprehensive documentation, including guides for installation and compilation, is hosted on Read the Docs:
